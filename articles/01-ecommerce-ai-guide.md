## 二、用AI生成商品主图（Midjourney / 可灵）

### 2.1 为什么要用AI做主图

商品主图是电商转化的第一道门。传统外包一张主图50-300元，改一版还要排队2天。AI做图**几分钟出图、无限改版、成本趋近于零**。

### 2.2 工具选择

| 工具 | 适合场景 | 价格 | 上手难度 |
|------|---------|------|---------|
| **可灵AI** | 国内直连、中文提示词、电商场景理解好 | 免费额度+付费约66元/月 | ★★☆☆☆ |
| **Midjourney** | 画质天花板、风格多样 | 约10美元/月（需科学上网） | ★★★☆☆ |
| **即梦AI**（字节） | 免费额度大、中文友好 | 免费起步 | ★★☆☆☆ |

**新手推荐：先用即梦AI免费练手，熟练后上可灵AI付费版。**

### 2.3 实操步骤（以可灵AI为例）

1. **打开可灵AI**：访问 klingai.com，注册登录
2. **选择"图像生成"模式**
3. **输入提示词**（中文即可）：
   ```
   一款白色陶瓷咖啡杯，放在木质桌面上，旁边有咖啡豆和绿植，
   自然光从左侧照入，电商产品主图风格，背景干净简洁，高画质，俯视角度
   ```
4. **设置参数**：比例选1:1（电商主图标准），画质选高清
5. **生成并筛选**：一次出4张，挑最满意的一张
6. **二次精修**：不满意就修改提示词重生成，比如加"暖色调""加蒸汽"等

### 2.4 成本估算

- 即梦AI免费版：**0元/月**（每天有免费额度）
- 可灵AI付费版：**约66元/月**，足够生成上百张图
- 对比传统外包：每月做30张主图，外包成本1500-9000元，AI成本66元

## 三、用AI写商品描述和营销文案（DeepSeek / Qwen）

### 3.1 痛点

写一条好的商品描述，要懂产品、懂卖点、懂消费者心理。很多小卖家自己写不出转化率高的文案，请文案策划又太贵。

### 3.2 工具选择

| 工具 | 特点 | 价格 |
|------|------|------|
| **DeepSeek** | 中文理解强、逻辑清晰、免费 | 免费（API也极便宜） |
| **通义千问（Qwen）** | 阿里出品、电商语料丰富 | 免费 |
| **豆包**（字节） | 响应快、口语化好 | 免费 |

### 3.3 实操步骤（以DeepSeek为例）

1. **打开 chat.deepseek.com**，注册登录
2. **输入结构化提示词**：

   ```
   你是一个10年经验的电商文案专家。请帮我写一条商品描述。

   商品信息：
   - 产品：手工陶瓷咖啡杯（350ml）
   - 卖点：手工拉胚、每一只独一无二、景德镇出品
   - 目标人群：25-40岁注重生活品质的都市白领
   - 价格区间：89-129元

   要求：
   1. 标题：15字以内，包含核心卖点
   2. 正文：200字左右，分3个卖点段落
   3. 结尾：一句促单引导语
   4. 语气：温暖有质感，不要硬广感
   ```

3. **生成后微调**：AI出的文案通常完成度80%以上，你只需调整个别措辞
4. **批量生产**：换不同产品信息，同一个提示词模板可以批量生成

### 3.4 进阶：生成整套营销素材

同一个DeepSeek对话中，你可以继续要求：
- "帮我把上面的描述改成小红书种草笔记风格"
- "写3条朋友圈推广文案"
- "写一条抖音短视频口播脚本，30秒"
- "生成5个商品标题供A/B测试"

**一个对话搞定一个商品的全套文案，过去要半天，现在10分钟。**

### 3.5 成本估算

- DeepSeek网页版：**完全免费**
- 通义千问：**完全免费**
- 如果用API批量调用：DeepSeek API约 **1元/百万token**，一个月写500条文案不到5块钱

## 四、AI客服自动回复

### 4.1 痛点

中小卖家最头疼的就是客服。买家问的问题80%是重复的："什么时候发货？""有现货吗？""尺码怎么选？"——但每个都得回，不回就丢单。

### 4.2 方案一：用平台自带AI客服

淘宝、拼多多、抖音电商都已内置AI客服助手：
- **淘宝**：千牛工作台 → 智能客服 → 开启"AI导购"
- **拼多多**：多多客服 → 智能回复 → 导入商品QA
- **抖音电商**：飞鸽客服 → 智能助手

**操作步骤**：
1. 进入后台客服设置页面
2. 导入你的商品信息（尺码表、发货时间、退换货政策）
3. 开启AI自动回复
4. 设置"转人工"触发条件（如买家连续两次表达不满）

**优点**：零成本、平台原生、不用维护
**缺点**：只能回答预设范围内的问题

### 4.3 方案二：用Dify搭建自定义AI客服（进阶）

如果你想接入微信私域客服或独立站，可以用 **Dify**（开源AI应用平台）搭建：

1. 注册 dify.ai，创建新应用
2. 选择"聊天助手"模板
3. 上传你的商品知识库（商品文档、FAQ、退换货政策）
4. 配置AI模型（选DeepSeek，几乎免费）
5. 设置系统提示词："你是XX店铺的客服，基于知识库回答问题，不知道就说转人工"
6. 发布并通过API接入你的客服渠道

### 4.4 成本估算

- 平台自带AI客服：**0元**
- Dify + DeepSeek API：**约10-30元/月**（取决于咨询量）

## 五、AI分析评论情感

### 5.1 为什么要做

商品评论是金矿。但几百条评论靠人工看完要半天，还容易遗漏。AI可以**5分钟帮你分类情感、提取高频问题、发现差评趋势**。

### 5.2 实操步骤

1. **导出评论数据**：从电商后台导出商品评论Excel
2. **打开DeepSeek或通义千问**，输入：

   ```
   我有一份商品评论数据，请帮我分析：
   1. 情感分类：正面/中性/负面各占比多少
   2. 提取正面评论的高频关键词（Top 10）
   3. 提取负面评论的核心问题（分类汇总）
   4. 给出3条产品改进建议

   评论数据如下：
   [粘贴评论内容]
   ```

3. **AI输出分析报告**，包含情感占比、关键词词云描述、问题分类
4. **根据分析结果行动**：差评集中在物流→换快递；集中在质量→找供应商谈

### 5.3 成本估算

- 用免费AI对话：**0元**
- 如果评论量大（1000条+），用API批量处理：**约2-5元/次**
